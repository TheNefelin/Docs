# Conexion
> [!NOTE]
> IDbConnection: Es una interfaz de .NET,

> [!NOTE]
> SqlConnection: Es una implementación de IDbConnection para SQL Server, que contiene metodos como OpenAsync.

## Entity Framework con SqlServer

### Dependencias
```
Microsoft.EntityFrameworkCore
Microsoft.EntityFrameworkCore.SqlServer
```
### Clase de Conexion
* Si solo se tiene una conexion
```csharp
public class EntityDbContext : DbContext
{
    public EntityDbContext(DbContextOptions options) : base(options)
    {
    }
}
```
* Mas de una conexion
```csharp
public class EntityDbContext : DbContext
{
    public EntityDbContext(DbContextOptions<EntityDbContext> options) : base(options)
    {
    }
}
```
### Configurar appsettings.json
```json
  "ConnectionStrings": {
    "SqlServerWeb": "Data Source=Servidor; Initial Catalog=db_testing; User ID=testing; Password=testing; TrustServerCertificate=True;",
    "SqlServer": "Server=localhost; Database=db_testing; User ID=testing; Password=testing; TrustServerCertificate=True;"
  },
```
### Injectar dependencia de conexion en Program.cs
```csharp
// Inyección para Entity Framework Core
builder.Services.AddDbContext<ApiDbContext>(options =>
{
    options.UseSqlServer(builder.Configuration.GetConnectionString("SqlServerWeb"));
});

// Inyección para conexiones genéricas 
builder.Services.AddTransient<IDbConnection>(options => // Dapper
    new SqlConnection(builder.Configuration.GetConnectionString("SqlServerWeb"))
);

//Inyección para SQL Server específicamente 
builder.Services.AddTransient<SqlConnection>(options => // Dapper
    new SqlConnection(builder.Configuration.GetConnectionString("SqlServerWeb"))
);
```

## Dapper con SqlServer

### Dependencias
```
Dapper
Microsoft.Data.SqlClient
```

### Queries Básicos
```csharp
// Obtener lista
public async Task<IEnumerable<Product>> GetAllAsync()
{
    using var connection = new SqlConnection(_connectionString);
    return await connection.QueryAsync<Product>("SELECT * FROM Products");
}

// Obtener por ID
public async Task<Product?> GetByIdAsync(int id)
{
    using var connection = new SqlConnection(_connectionString);
    return await connection.QueryFirstOrDefaultAsync<Product>(
        "SELECT * FROM Products WHERE Id = @Id", 
        new { Id = id });
}

// Insertar
public async Task<int> InsertAsync(Product product)
{
    using var connection = new SqlConnection(_connectionString);
    var sql = @"INSERT INTO Products (Name, Price) 
                VALUES (@Name, @Price);
                SELECT CAST(SCOPE_IDENTITY() as int)";
    return await connection.ExecuteScalarAsync<int>(sql, product);
}

// Actualizar
public async Task<bool> UpdateAsync(Product product)
{
    using var connection = new SqlConnection(_connectionString);
    var rows = await connection.ExecuteAsync(
        "UPDATE Products SET Name = @Name, Price = @Price WHERE Id = @Id", 
        product);
    return rows > 0;
}

// Eliminar
public async Task<bool> DeleteAsync(int id)
{
    using var connection = new SqlConnection(_connectionString);
    var rows = await connection.ExecuteAsync(
        "DELETE FROM Products WHERE Id = @Id", 
        new { Id = id });
    return rows > 0;
}
```

### Queries con Parámetros Dinámicos
```csharp
// Paginación
public async Task<PaginatedResult<Product>> GetPaginatedAsync(int page, int limit, string? search)
{
    using var connection = new SqlConnection(_connectionString);
    
    var sql = "SELECT * FROM Products";
    var countSql = "SELECT COUNT(*) FROM Products";
    
    if (!string.IsNullOrEmpty(search))
    {
        sql += " WHERE Name LIKE @Search";
        countSql += " WHERE Name LIKE @Search";
    }
    
    sql += " ORDER BY Id OFFSET @Offset ROWS FETCH NEXT @Limit ROWS";
    
    var total = await connection.ExecuteScalarAsync<int>(countSql, new { Search = $"%{search}%" });
    var items = await connection.QueryAsync<Product>(sql, new { 
        Search = $"%{search}%", 
        Offset = (page - 1) * limit, 
        Limit = limit 
    });
    
    return new PaginatedResult<Product>(items, total, page, limit);
}
```

### Transacciones
```csharp
public async Task<bool> CreateOrderWithItems(Order order, List<OrderItem> items)
{
    using var connection = new SqlConnection(_connectionString);
    connection.Open();
    
    using var transaction = connection.BeginTransaction();
    
    try
    {
        var orderId = await connection.ExecuteScalarAsync<int>(
            "INSERT INTO Orders (CustomerId, Total) VALUES (@CustomerId, @Total); SELECT SCOPE_IDENTITY()",
            order, transaction);
        
        foreach (var item in items)
        {
            await connection.ExecuteAsync(
                "INSERT INTO OrderItems (OrderId, ProductId, Quantity) VALUES (@OrderId, @ProductId, @Quantity)",
                new { OrderId = orderId, item.ProductId, item.Quantity },
                transaction);
        }
        
        transaction.Commit();
        return true;
    }
    catch
    {
        transaction.Rollback();
        return false;
    }
}
```

# Migracion

### Dependencies
```
Microsoft.EntityFrameworkCore
Microsoft.EntityFrameworkCore.SqlServer
Microsoft.EntityFrameworkCore.Design
```

### Configurar Migration
```csharp
// En Program.cs
builder.Services.AddDbContext<ApiDbContext>(options =>
    options.UseSqlServer(builder.Configuration.GetConnectionString("SqlServerWeb")));
```

### Comandos de Migración (CLI)
```bash
# Agregar migración inicial
dotnet ef migrations add InitialCreate

# Agregar nueva migración
dotnet ef migrations add AddProductsTable

# Ver lista de migraciones
dotnet ef migrations list

# Aplicar migraciones al database
dotnet ef database update

# Aplicar migración específica
dotnet ef database update <MigrationName>

# Eliminar última migración (sin aplicar)
dotnet ef migrations remove

# Generar script SQL
dotnet ef migrations script

# Script desde una migración específica
dotnet ef migrations script <FromMigration> <ToMigration>
```

### Seeds (Datos Iniciales)
```csharp
// En DbContext
public class ApiDbContext : DbContext
{
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        base.OnModelCreating(modelBuilder);
        
        // Seed data
        modelBuilder.Entity<Category>().HasData(
            new Category { Id = 1, Name = "Electronics" },
            new Category { Id = 2, Name = "Clothing" }
        );
        
        modelBuilder.Entity<Product>().HasData(
            new Product { Id = 1, Name = "Laptop", Price = 999.99m, CategoryId = 1 }
        );
    }
}
