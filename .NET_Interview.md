## Fundamentos y lógica
### 1. En C#, ¿cuál es la diferencia entre int, var y dynamic? ¿Cuándo usarías cada uno?
```
int es un tipo de dato estático que representa números enteros. Su tipo está definido en tiempo de compilación y no puede cambiar.

var es una palabra clave para inferencia de tipos en tiempo de compilación. El compilador determina el tipo exacto basándose en el valor asignado. Por ejemplo, var x = 10; lo convierte en un int. Pero el tipo ya no cambia.

dynamic permite que el tipo se determine en tiempo de ejecución. Es similar a JavaScript: puedes asignarle cualquier valor, y puede cambiar de tipo más adelante. Útil, pero peligroso si no se controla.
```

### 2. Escribe una función en C# que imprima los números del 1 al 100, pero:
- Si el número es divisible por 3, imprime "Fizz".
- Si es divisible por 5, imprime "Buzz".
- Si es divisible por ambos, imprime "FizzBuzz".
- Si no es divisible por ninguno, imprime el número.
```
static void FizzBuzz()
{
    for (int i = 1; i <= 100; i++)
    {
        if (i % 3 == 0 && i % 5 == 0) Console.WriteLine(i + " FizzBuzz");
        else if (i % 3 == 0) Console.WriteLine(i + " Fizz");
        else if (i % 5 == 0) Console.WriteLine(i + " Buzz");
        else Console.WriteLine(i);
    }
}

FizzBuzz();
```

## Conceptos de POO
### 1. ¿Puedes explicar brevemente qué significan estos 4 pilares de la programación orientada a objetos?
- Encapsulamiento
- Herencia
- Polimorfismo
- Abstracción
```
Encapsulamiento:
Es el principio que permite ocultar los detalles internos de una clase. Se logra usando modificadores de acceso como private, y se exponen los datos a través de métodos públicos (getters y setters). Esto protege los datos y mantiene la lógica controlada.
```
```
Herencia:
Permite que una clase (hija) herede atributos y métodos de otra clase (padre). En C# se usa : para indicar herencia.
También puedes sobrescribir métodos usando virtual en la clase base y override en la clase hija.
Ejemplo: class Perro : Animal { }
```
```
Polimorfismo:
Significa "muchas formas". En C#, puede lograrse de dos formas:

Polimorfismo de sobrecarga: varios métodos con el mismo nombre pero distintos parámetros.

Polimorfismo de sobreescritura: una clase hija redefine el comportamiento de un método padre con override.
También aplica al usar interfaces o clases abstractas donde cada implementación tiene su propia lógica.
```
```
Abstracción:
Es ocultar la complejidad y mostrar solo lo esencial.
Se logra con clases abstractas o interfaces, donde defines lo que una clase debe hacer, pero no cómo lo hace.
Así forzas a las clases hijas a implementar solo lo importante, sin saber cómo funciona internamente.
```

### 2. Crea una clase Animal que tenga:
- Un método HacerSonido() que sea virtual.
- Dos clases hijas: Perro y Gato, que sobrescriban ese método y digan "Guau" y "Miau" respectivamente.
- En tu Main(), crea una lista de Animal y añade un Perro y un Gato, luego recorre la lista y llama HacerSonido().

```
{
    public virtual void HacerSonido() { }
}
```
```
public class Perro : Animal

    public override void HacerSonido()

        Console.WriteLine("Guau");
    }
```

```
public class Gato : Animal

    public override void HacerSonido()
    {
        Console.WriteLine("Miau");
    }

```
```
List<Animal> animales = new List<Animal> { new Perro(), new Gato() };

foreach (var animal in animales)
{
    animal.HacerSonido();
}
```

### 3. ¿Cuál es la diferencia entre == y .Equals() en C#?
```
== compara referencias en objetos (como clases) y valores en tipos primitivos (como int, bool, char).

.Equals() compara el contenido de los objetos, y se puede sobreescribir para personalizar la comparación.

string a = "hola";
string b = "hola";
Console.WriteLine(a == b);       // True
Console.WriteLine(a.Equals(b));  // True
```

### 4. ¿Qué es el using en C# y para qué se usa?
```
El bloque using para liberar recursos automáticamente (como archivos o conexiones a BD).

using (var reader = new StreamReader("archivo.txt"))
{
    var contenido = reader.ReadToEnd();
}
```

### 5. ¿Qué hace el operador ?? en C#?
```
?? se llama null-coalescing operator
Devuelve el valor de la izquierda si no es null, y si lo es, devuelve el de la derecha.

string nombre = null;
string resultado = nombre ?? "Invitado";
Console.WriteLine(resultado); // "Invitado"
```

### 6. ¿Cuál es la diferencia entre interface y abstract class?
```
| Característica     | Interface                         | Clase Abstracta
|--------------------|-----------------------------------|------------------------------------
| Se instancia       | ❌ No                             | ❌ No
| Puede tener lógica | ✅ (desde C# 8.0) con `default`   | ✅ Sí, puede tener implementación
| Herencia múltiple  | ✅ Sí, puedes implementar varias  | ❌ Solo una clase base abstracta
| Propósito          | Contrato puro                      | Base común + comportamiento parcial
```

### 7. Crea una clase Empleado que tenga:
- Propiedades: Nombre, SueldoBase, HorasExtras.
- Un método CalcularSueldoTotal() que devuelva el sueldo total suponiendo que:
- Cada hora extra vale $15 adicionales al sueldo base.
```
public class Empleado
{
    public string Nombre { get; set; }
    public int SueldoBase { get; set; }
    public int HorasExtras { get; set; }

    public int CalcularSueldoTotal()
    {
        return SueldoBase + (HorasExtras * 15);
    }
}
```
```
var empleado = new Empleado
{
    Nombre = "Netero",
    SueldoBase = 1000,
    HorasExtras = 5
};

Console.WriteLine($"El sueldo total de {empleado.Nombre} es: {empleado.CalcularSueldoTotal()}");
```

### 8. Ordenar números de mayor a menor (sin .Sort())
- Tienes un arreglo de enteros int[] numeros = { 5, 2, 9, 1, 3 };.
- Ordena el arreglo de mayor a menor manualmente usando un algoritmo clásico (ej: Bubble Sort, Selection Sort, etc.).
```
int[] numeros = { 5, 2, 9, 1, 7 };

for (int i = 0; i < numeros.Length - 1; i++)
{
    for (int j = 0; j < numeros.Length - 1 - i; j++)
    {
        if (numeros[j] < numeros[j + 1]) // cambio para orden DESCENDENTE
        {
            int temp = numeros[j];
            numeros[j] = numeros[j + 1];
            numeros[j + 1] = temp;
        }
    }
}

Console.WriteLine("Arreglo ordenado de mayor a menor:");
foreach (var num in numeros)
{
    Console.Write(num + " ");
}
```
```
int[] numeros = { 4, 2, 3, 1, 5 };

for (int i = 0; i < numeros.Length - 1; i++)
{
    bool swapped = false;

    for (int j = 0; j < numeros.Length - 1 - i; j++)
    {
        if (numeros[j] > numeros[j + 1])
        {
            int temp = numeros[j];
            numeros[j] = numeros[j + 1];
            numeros[j + 1] = temp;
            swapped = true; // Se hizo un intercambio
        }
    }

    // Si no se intercambió nada, ya está ordenado
    if (!swapped)
    {
        break;
    }
}

Console.WriteLine("Arreglo ordenado:");
foreach (var num in numeros)
{
    Console.Write(num + " ");
}
```

### 9. Ordenar textos alfabéticamente sin .Sort()
- Tienes un arreglo de strings string[] nombres = { "Carlos", "Ana", "Luis", "Bea", "Daniel" };
- Ordénalos alfabéticamente A–Z manualmente (comparando letras).
```
string[] nombres = { "Carlos", "Ana", "Luis", "Bea" };

for (int i = 0; i < nombres.Length - 1; i++)
{
    for (int j = 0; j < nombres.Length - 1 - i; j++)
    {
        if (nombres[j].CompareTo(nombres[j + 1]) > 0) // orden alfabético ascendente
        {
            string temp = nombres[j];
            nombres[j] = nombres[j + 1];
            nombres[j + 1] = temp;
        }
    }
}

Console.WriteLine("Nombres ordenados alfabéticamente:");
foreach (var nombre in nombres)
{
    Console.Write(nombre + " ");
}
```
