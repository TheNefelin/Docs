## Pregunta 01
### Cual es la complejidad temporal del algoritmo Merge Sort en el peor de los casos?
- ❌ O(n ^ 2)
- ❌ O(n)
- ✅ O(n log n)
- ❌ O(n ^ n)

Explicación:
Merge Sort tiene una complejidad temporal de O(n log n) en todos los casos (mejor caso, caso promedio y peor caso). Esto es porque:

1. Fase de división: El algoritmo divide el array en mitades recursivamente, lo que genera un árbol de profundidad log n
2. Fase de fusión: En cada nivel del árbol, se procesan todos los n elementos
3. Total: n elementos × log n niveles = O(n log n)

```csharp
public class MergeSortExample
{
    public static void MergeSort(int[] arr, int left, int right)
    {
        if (left < right)
        {
            int mid = left + (right - left) / 2;
            
            // Dividir
            MergeSort(arr, left, mid);        // O(log n)
            MergeSort(arr, mid + 1, right);   // O(log n)
            
            // Fusionar
            Merge(arr, left, mid, right);     // O(n)
        }
    }
    
    private static void Merge(int[] arr, int left, int mid, int right)
    {
        int n1 = mid - left + 1;
        int n2 = right - mid;
        
        int[] leftArr = new int[n1];
        int[] rightArr = new int[n2];
        
        Array.Copy(arr, left, leftArr, 0, n1);
        Array.Copy(arr, mid + 1, rightArr, 0, n2);
        
        int i = 0, j = 0, k = left;
        
        while (i < n1 && j < n2)
        {
            if (leftArr[i] <= rightArr[j])
                arr[k++] = leftArr[i++];
            else
                arr[k++] = rightArr[j++];
        }
        
        while (i < n1)
            arr[k++] = leftArr[i++];
        
        while (j < n2)
            arr[k++] = rightArr[j++];
    }
}

// Uso:
int[] numeros = { 38, 27, 43, 3, 9, 82, 10 };
MergeSort(numeros, 0, numeros.Length - 1);
// Resultado: { 3, 9, 10, 27, 38, 43, 82 }
```

## Pregunta 02
### Cual es la complejidad temporal promedio del algoritmo QuickSort?
- ❌ O(n²)
- ❌ O(n)
- ❌ O(n ^ n)
- ✅ O(n log n)

Explicación:
QuickSort tiene una complejidad temporal promedio de O(n log n). Aunque en el peor caso puede ser O(n²) (cuando el pivote elegido es siempre el elemento mínimo o máximo), en la mayoría de los casos prácticos el rendimiento es muy eficiente.

1. Partición: Divide el array usando un pivote - O(n)
2. Recursión: Procesa los subarrays recursivamente - O(log n) en promedio
3. Total promedio: n elementos × log n niveles = O(n log n)

```csharp
public class QuickSortExample
{
    public static void QuickSort(int[] arr, int low, int high)
    {
        if (low < high)
        {
            int pi = Partition(arr, low, high);
            
            QuickSort(arr, low, pi - 1);      // Ordenar elementos < pivote
            QuickSort(arr, pi + 1, high);     // Ordenar elementos > pivote
        }
    }
    
    private static int Partition(int[] arr, int low, int high)
    {
        int pivot = arr[high];
        int i = low - 1;
        
        for (int j = low; j < high; j++)
        {
            if (arr[j] < pivot)
            {
                i++;
                // Intercambiar
                int temp = arr[i];
                arr[i] = arr[j];
                arr[j] = temp;
            }
        }
        
        // Intercambiar pivote
        int temp2 = arr[i + 1];
        arr[i + 1] = arr[high];
        arr[high] = temp2;
        
        return i + 1;
    }
}

// Uso:
int[] numeros = { 64, 34, 25, 12, 22, 11, 90 };
QuickSort(numeros, 0, numeros.Length - 1);
// Resultado: { 11, 12, 22, 25, 34, 64, 90 }
```

## Pregunta 03
### Que método usarías para buscar un número en un arreglo (Array) ordenado de números?
- ❌ Linear Search
- ❌ Llenar una lista de hash y luego buscar por dicho hash
- ❌ Llenar un árbol binario (Dictionary Tree) y luego buscar en el árbol
- ✅ Binary Search

Explicación:
Binary Search es el algoritmo más eficiente para buscar en un array ordenado con complejidad O(log n). Funciona dividiendo el array por la mitad en cada iteración, descartando la mitad donde el elemento no puede estar.

```csharp
public class BinarySearchExample
{
    public static int BinarySearch(int[] arr, int target)
    {
        int left = 0;
        int right = arr.Length - 1;
        
        while (left <= right)
        {
            int mid = left + (right - left) / 2;
            
            if (arr[mid] == target)
                return mid;
            
            if (arr[mid] < target)
                left = mid + 1;
            else
                right = mid - 1;
        }
        
        return -1; // No encontrado
    }
}

// Uso:
int[] numeros = { 2, 5, 8, 12, 16, 23, 38, 45, 56, 67 };
int resultado = BinarySearch(numeros, 23);
// Resultado: 5 (índice donde se encuentra 23)
```

## Pregunta 04
### Suponiendo que el tiempo de ejecución de un algoritmo posee un ratio de crecimiento cuadrático. Para un tamaño de entrada de 1000 posee un tiempo de ejecución de 20ms. ¿Cuál sería tu estimado de tiempo de ejecución para una entrada de tamaño 10000?
- ❌ 400 ms
- ✅ 2000 ms
- ❌ 200 ms
- ❌ 4000 ms

Explicación:
Con complejidad O(n²), el tiempo es proporcional al cuadrado del tamaño de entrada. Si aumentamos de 1000 a 10000 (10 veces más), el tiempo se multiplica por 10² = 100.

Cálculo: 20ms × 100 = 2000ms

```csharp
// Demostración conceptual
public class ComplexityGrowth
{
    // O(n²)
    public static long MeasureQuadraticTime(int n)
    {
        long count = 0;
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                count++;
        return count;
    }
}

// Para n=1000: aproximadamente 1,000,000 operaciones -> 20ms
// Para n=10000: aproximadamente 100,000,000 operaciones -> 2000ms
```

## Pregunta 05
### ¿Qué estructura de datos es necesaria para realizar un procedimiento recursivo?
- ✅ Pila (Stack)
- ❌ Arreglo (Array)
- ❌ Lista priorizada (Priority List)
- ❌ Cola (Queue)

Explicación:
La Pila (Stack) es la estructura fundamental para la recursión. Cada llamada recursiva se apila en la pila de ejecución (call stack), y cuando la función retorna, se desapila. Esto permite mantener el contexto de cada nivel de recursión.

```csharp
public class RecursionExample
{
    // La recursión usa internamente una pila (call stack)
    public static int Factorial(int n)
    {
        // Caso base
        if (n <= 1)
            return 1;
        
        // Caso recursivo - genera una entrada en la pila
        return n * Factorial(n - 1);
    }
}

// Uso:
int resultado = Factorial(5);
// Resultado: 120

// Secuencia de la pila:
// Factorial(5) -> 5 * Factorial(4)
// Factorial(4) -> 4 * Factorial(3)
// Factorial(3) -> 3 * Factorial(2)
// Factorial(2) -> 2 * Factorial(1)
// Factorial(1) -> 1 (caso base, se desapila)
```

## Pregunta 06
### ¿Cuál es el mejor uso para un árbol?
- ❌ Indicar registros en una base de datos
- ❌ Cola de impresión (Print Queue)
- ❌ Procesamiento de imágenes
- ✅ Búsqueda y organización jerárquica de datos

Explicación:
Los árboles son estructuras óptimas para búsqueda, inserción y eliminación eficiente de datos, especialmente en árboles balanceados como AVL o Red-Black. También son ideales para representar relaciones jerárquicas (sistemas de archivos, organización empresarial, estructuras DOM en HTML).

```csharp
public class BinarySearchTree
{
    public class Node
    {
        public int Value;
        public Node Left;
        public Node Right;
        
        public Node(int value)
        {
            Value = value;
        }
    }
    
    private Node root;
    
    public void Insert(int value)
    {
        root = InsertRecursive(root, value);
    }
    
    private Node InsertRecursive(Node node, int value)
    {
        if (node == null)
            return new Node(value);
        
        if (value < node.Value)
            node.Left = InsertRecursive(node.Left, value);
        else if (value > node.Value)
            node.Right = InsertRecursive(node.Right, value);
        
        return node;
    }
}
```

## Pregunta 07
### ¿Cuál es la complejidad temporal de insertar un elemento en un árbol balanceado en el peor de los casos?
- ❌ O(n ^ 2)
- ❌ O(1)
- ✅ O(log n)
- ❌ O(n ^ n)

Explicación:
En un árbol balanceado (como AVL o Red-Black), la altura máxima es O(log n), por lo que insertar requiere descender desde la raíz hasta la posición correcta, lo que toma O(log n) operaciones en el peor caso.

```csharp
public class BalancedTreeInsertion
{
    public class AVLNode
    {
        public int Value;
        public AVLNode Left;
        public AVLNode Right;
        public int Height;
        
        public AVLNode(int value)
        {
            Value = value;
            Height = 1;
        }
    }
    
    private int GetHeight(AVLNode node)
    {
        return node == null ? 0 : node.Height;
    }
    
    private int GetBalance(AVLNode node)
    {
        return node == null ? 0 : GetHeight(node.Left) - GetHeight(node.Right);
    }
    
    public AVLNode Insert(AVLNode node, int value)
    {
        if (node == null)
            return new AVLNode(value); // O(1)
        
        if (value < node.Value)
            node.Left = Insert(node.Left, value); // O(log n)
        else if (value > node.Value)
            node.Right = Insert(node.Right, value); // O(log n)
        
        node.Height = 1 + Math.Max(GetHeight(node.Left), GetHeight(node.Right));
        
        // Balanceo automático
        int balance = GetBalance(node);
        
        if (balance > 1 && value < node.Left.Value)
            return RotateRight(node);
        
        if (balance < -1 && value > node.Right.Value)
            return RotateLeft(node);
        
        return node;
    }
    
    private AVLNode RotateRight(AVLNode y)
    {
        AVLNode x = y.Left;
        AVLNode T2 = x.Right;
        
        x.Right = y;
        y.Left = T2;
        
        y.Height = 1 + Math.Max(GetHeight(y.Left), GetHeight(y.Right));
        x.Height = 1 + Math.Max(GetHeight(x.Left), GetHeight(x.Right));
        
        return x;
    }
    
    private AVLNode RotateLeft(AVLNode x)
    {
        AVLNode y = x.Right;
        AVLNode T2 = y.Left;
        
        y.Left = x;
        x.Right = T2;
        
        x.Height = 1 + Math.Max(GetHeight(x.Left), GetHeight(x.Right));
        y.Height = 1 + Math.Max(GetHeight(y.Left), GetHeight(y.Right));
        
        return y;
    }
}
```

## Pregunta 08
### Dado el siguiente pseudocódigo. ¿Cuál sería el resultado para el siguiente árbol?
```
imprimirArbol(arbol){
  if (arbol.tieneIzquierda){
    imprimirArbol(arbol.Izquierda)
  }
  if (arbol.tieneDerecha){
    imprimirArbol(arbol.Derecha)
  }
  imprimir(nodoActual)
}
```

Árbol:
```
        10
       /  \
      5    23
     / \   / \
    2   7 18 31
     \
      5
```

- ❌ 2-5-5-7-10-18-23-31
- ❌ 10-5-23-2-7-18-31-5
- ✅ 2-5-7-5-18-31-23-10
- ❌ 5-2-7-18-31-5-23-10

Explicación:
Este es un recorrido Post-orden (Post-order): izquierda → derecha → nodo actual. Se visita el nodo actual al final después de procesar sus subárboles.

Traza:
1. Izquierda(5) → Izquierda(2) → Imprime: 2
2. Derecha(2-5) → Imprime: 5
3. Imprime: 5 (nodo 5)
4. Derecha(7) → Imprime: 7
5. Imprime: 5 (nodo padre)
6. Izquierda(23-18) → Imprime: 18
7. Derecha(23-31) → Imprime: 31
8. Imprime: 23
9. Imprime: 10

```csharp
public class TreeTraversal
{
    public class TreeNode
    {
        public int Value;
        public TreeNode Left;
        public TreeNode Right;
        
        public TreeNode(int value)
        {
            Value = value;
        }
    }
    
    // Post-order: Izquierda → Derecha → Nodo
    public static void PostOrder(TreeNode node)
    {
        if (node == null)
            return;
        
        PostOrder(node.Left);
        PostOrder(node.Right);
        Console.Write(node.Value + "-");
    }
}
```

## Pregunta 09
### Si tuviera que ordenar un arreglo (array) muy grande almacenado en disco que no cabe en la memoria. ¿Qué algoritmo utilizaría?
- ❌ Bubble Sort
- ✅ Merge Sort
- ❌ Quick Sort
- ❌ Heap Sort

Explicación:
Merge Sort es ideal para datos externos (en disco) porque utiliza acceso secuencial a los datos, minimizando las operaciones de I/O. Realiza múltiples pasadas dividiendo el archivo en bloques que caben en memoria, luego los fusiona ordenadamente. Quick Sort requiere acceso aleatorio, y Bubble Sort y Heap Sort son demasiado ineficientes para grandes volúmenes.

## Pregunta 10
### Usted debe invertir el orden de una lista enlazada (Linked List). ¿Qué estructura de datos auxiliar se necesita?
- ❌ Cola (Queue)
- ✅ Pila (Stack)
- ❌ Ninguna
- ❌ Árbol (Tree)

Explicación:
Una Pila (Stack) es la estructura ideal para invertir una lista enlazada. Se apilan todos los nodos en orden original y luego se desapilan para construir la lista invertida en orden inverso. También es posible hacerlo sin estructura auxiliar usando recursión (que usa la pila de llamadas internamente).

```csharp
public class ReverseLinkedList
{
    public class Node
    {
        public int Value;
        public Node Next;
        
        public Node(int value)
        {
            Value = value;
        }
    }
    
    // Método 1: Usando Stack
    public static Node ReverseWithStack(Node head)
    {
        var stack = new Stack<int>();
        Node current = head;
        
        // Apilar todos los valores
        while (current != null)
        {
            stack.Push(current.Value);
            current = current.Next;
        }
        
        // Desapilar para crear lista invertida
        if (stack.Count == 0)
            return null;
        
        Node newHead = new Node(stack.Pop());
        current = newHead;
        
        while (stack.Count > 0)
        {
            current.Next = new Node(stack.Pop());
            current = current.Next;
        }
        
        return newHead;
    }
    
    // Método 2: Iterativo sin estructura auxiliar
    public static Node ReverseIterative(Node head)
    {
        Node prev = null;
        Node current = head;
        
        while (current != null)
        {
            Node next = current.Next;
            current.Next = prev;
            prev = current;
            current = next;
        }
        
        return prev;
    }
}

// Uso:
var head = new ReverseLinkedList.Node(1);
head.Next = new ReverseLinkedList.Node(2);
head.Next.Next = new ReverseLinkedList.Node(3);

var reversed = ReverseLinkedList.ReverseWithStack(head);
// Lista original: 1 → 2 → 3
// Lista invertida: 3 → 2 → 1
```
